# Gymix – Team Distribution

## Team Structure

The Gymix project will be developed by four team members.

## Member 1 – Frontend Developer

**Responsibilities: Admin Dashboard**

- Build the administrator interface using React.js.
- Create dashboard pages and navigation.
- Build member management pages.
- Build coach management pages.
- Build subscription management pages.
- Build training session management pages.
- Connect the dashboard with backend APIs.

## Member 2 – Frontend Developer

**Responsibilities: Member and Coach Dashboards**

- Build the member dashboard using React.js.
- Build the coach read-only dashboard.
- Create member profile and subscription pages.
- Create session browsing and booking pages.
- Display booking history and attendance.
- Display coach schedules and assigned sessions.
- Create the Contact Admin feature.
- Connect dashboards with backend APIs.

## Member 3 – Backend Developer

**Technology: Node.js**

**Responsibilities:**

- Authentication and authorization.
- User management.
- Member management.
- Subscription plans management.
- Member subscriptions.
- Subscription expiration and status.
- Session booking and cancellation.
- Booking history.
- Remaining membership benefits, in coordination with the ASP.NET Core backend.

## Member 4 – Backend Developer

**Technology: ASP.NET Core**

**Responsibilities:**

- Coach management.
- Training session management.
- Session schedules.
- Session capacity management.
- Attendance management.
- Session fees and benefits tracking.
- Coach requests and communication with administrators.

## Shared Responsibilities

All team members are responsible for:

- Participating in planning and meetings.
- Following the agreed coding standards.
- Testing their assigned features.
- Reviewing code through Pull Requests.
- Updating project documentation.
- Supporting integration between project components.

## Important Notes

- Each member should work on assigned tasks.
- Changes should be submitted through Pull Requests.
- The team must agree on database design and API contracts before implementation.
- Both backend developers must coordinate authentication, user IDs, and data exchange between services.
