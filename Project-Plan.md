# Gymix – Project Plan

## 1. Project Overview

Gymix is a web-based Gym Management System that aims to organize and simplify gym operations through three user roles: Administrator, Coach, and Gym Member.

The project will be developed by a team of four members over an estimated period of 30 days.

## 2. Project Goals

- Build a user-friendly gym management system.
- Provide separate dashboards based on user roles.
- Manage members, coaches, and subscriptions.
- Organize training sessions and schedules.
- Support session booking and cancellation.
- Track attendance and membership benefits.
- Provide communication between coaches and administrators.

## 3. Project Scope

### Included Features

- User authentication and authorization.
- Member and coach management.
- Subscription plan management.
- Training session and schedule management.
- Session booking and cancellation.
- Attendance tracking.
- Free and paid session tracking.
- Coach requests to administrators.

### Not Included in the Initial Version

- Mobile application.
- Online payment gateway integration.
- Advanced financial reports.
- Biometric attendance systems.

These features may be considered for future development.

## 4. Technologies

- Frontend: React.js
- Backend: Node.js
- Backend: ASP.NET Core
- Database: To be determined.

## 5. Development Approach

The project will be developed in stages:

1. Requirements analysis and planning.
2. Database design and project setup.
3. Backend development.
4. Frontend development.
5. Integration between frontend and backend.
6. Testing and bug fixing.
7. Final documentation and presentation.

## 6. Expected Deliverables

- Functional web application.
- Administrator dashboard.
- Member dashboard.
- Coach read-only dashboard.
- Backend APIs.
- Database design.
- Project documentation.
- Final project presentation.

## 7. Project Duration

Estimated duration: 30 days.

The team will prioritize the core system features and may adjust the scope according to development progress.
