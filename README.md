# Gymix – Gym Management System

Gymix is a web-based Gym Management System designed to simplify and automate gym operations.

The system provides three different dashboards for Administrators, Coaches, and Gym Members.

## Main Features

- User Authentication and Authorization
- Member Management
- Coach Management
- Subscription Plans Management
- Training Sessions Management
- Session Booking
- Attendance Tracking
- Membership Benefits Management
- Coach-Admin Communication

## User Roles

- **Administrator:** Full control over gym operations.
- **Coach:** Read-only dashboard with the ability to contact the administrator.
- **Member:** Manage membership, browse sessions, and book training sessions.

## Technologies
